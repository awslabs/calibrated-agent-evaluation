Not sure yet whether you need it? [Why Calibrated Agent Evaluation](../why/index.md) shows the problem with numbers.

New here? Run this first; it needs nothing but the base install:

```bash
pip install calibrated-agent-evaluation
calibrated-agent-evaluation quickstart
```

Then run `calibrated-agent-evaluation doctor` to see which optional extras you have and the exact
line to add any you need.
